# 豆瓣 Top250 数据更新

页面：`douban.html`，快照：`assets/douban.json`。

在仓库根目录运行：

```sh
python -m pip install beautifulsoup4 tzdata
python scripts/update_douban.py
```

脚本读取用户 257515089 的公开记录，以及电影、书籍各 250 条榜单。
只保存标题、条目 ID 和个人评分，不读取登录凭据、评论或标记日期。
完整获取并核对数量后才替换快照；网络拒绝或解析失败时保留旧快照。
完成后按网站原有发布方式发布文件。页面不会在访客浏览器中跨域抓取豆瓣。

`.github/workflows/update-douban.yml` 每月 1 日上海时间 11:23 自动刷新
两个榜单和公开的完成清单，也可通过 GitHub Actions 手动运行。
提交并推送到默认分支后定时任务才会生效，GitHub 调度可能延迟。
豆瓣可能拒绝 GitHub 服务器的请求；失败时任务会报错并保留旧快照，
页面上的更新日期可用于判断数据是否过期。必要时可本地运行脚本更新。
快照提交使用正常 commit 消息，以便仓库现有的 Pages 构建方式部署更新。

页面默认显示已完成作品，不按标记日期分析。进度随最新榜单及公开记录
变化。书籍以条目 ID 精确匹配，不会合并不同版本。
与 KTV 一样不在导航、Interests 或 sitemap 中放入口，并设置 noindex。
通过链接仍可访问，不具备身份验证。

「不想看 / 不想读」以类别和豆瓣条目 ID 保存在浏览器 localStorage，
不会写入豆瓣或仓库。每月刷新榜单不会覆盖；退出榜单的条目选择仍保留，
再次入榜时恢复标记。之后在豆瓣标记完成的作品优先显示已完成。
换设备或清除浏览器数据前可导出 JSON 备份，再导入合并到新浏览器。
本地预览和正式网站属于不同来源，需要用备份迁移选择。

本地预览：`python -m http.server 8765`，访问
`http://localhost:8765/douban.html`。不要以 file:// 方式打开，组件和 JSON
需要 HTTP 服务。
